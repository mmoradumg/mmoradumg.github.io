هل التطبيق متاح على App Store؟Is the app available on the App Store?

الإصدار 4.0.1 المشار إليه هنا إصدار تجريبي. لا نعلن إتاحته تجاريًا حتى يتم نشره رسميًا.Version 4.0.1 is a test build. Public availability will be announced only after an official release.

هل ملف IPA غير الموقع يتثبت مباشرة؟Can an unsigned IPA install directly?

لا. يحتاج التطبيق إلى توقيع وتوزيع معتمدين من Apple أو وسيلة اختبار متوافقة.No. iOS installation requires valid signing and an approved or compatible testing distribution method.

كيف أطلب حذف بيانات الحساب؟How can I request account-data deletion?

راسل gm@umg-eg.com بعنوان «DOLLAR Data Deletion». سنراجع الطلب ونوضح إمكانية الحذف والبيانات التي قد يلزم الاحتفاظ بها قانونيًا.Email gm@umg-eg.com with the subject “DOLLAR Data Deletion.” We will review the request and explain what can be erased and any required legal retention.
